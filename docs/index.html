提出物Ultra

締切ではなく、まだ間に合う「最後の開始時刻」を知らせる Android アプリです。

最後の開始時刻 ＝ 期限 −（作業時間 ＋ 余裕時間）

この時刻を過ぎても終わっていなければ、鳴ります。

できること

  • 緊急通知
  • 全画面アラーム
  • リマインダー通知
  • カウントダウン
  • 完了の記録

必要な権限

  • 通知の表示
  • 正確なアラーム
  • おやすみモードへのアクセス
  • 全画面通知
  • 他のアプリの上に表示
  • バッテリー最適化の除外

プライバシー

通信は行いません。バックアップもしないので、すべては端末の中だけにあります。

つくりかた

このアプリの開発には Claude Code を使っています。Vibe Coding はしていません。

更新履歴

1.6.02026-08-04

緊急通知が時刻どおりに鳴らないことがある問題を直しました。アラームを目覚まし時計と同じ方式で予約するようにして、省電力機能に遅らされなくなっています。アプリを更新したあともアラームが消えなくなり、万一止まっていた場合は状態画面で分かります。

1.5.02026-07-25

緊急通知の画面を作り直しました。カウントダウンを主役に項目を絞り、暗い配色とハザードテープ、秒に合わせて脈打つ縁にしています。

1.4.02026-07-25

Android の自動バックアップを無効にしました。データが Google のサーバーに保存されなくなり、アンインストールで確実に消えます。

1.3.02026-07-25

初回起動時に、追加・完了・削除のしかたを見せるチュートリアルを追加しました。設定の「使い方」からいつでも見返せます。

1.2.02026-07-25

省電力機能の強い OS（HyperOS・MIUI・ColorOS）を検出し、初回起動時に警告するようにしました。

1.1.12026-07-25

全画面アラームを強化しました。期限後は表示を切り替え、鳴らし続け、戻るキーでは閉じられません。

1.1.02026-07-25

初回公開。
