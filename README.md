# 提出物Ultra

提出物をうっかり出し忘れないための Android アプリです。

締切の時刻ではなく、「これを過ぎたらたぶん間に合わない」という開始時刻を出します。

```
開始時刻 = 期限 −（作業時間 ＋ 余裕時間）
```

その時刻になっても終わっていなければ通知が鳴ります。マナーモードやおやすみモードでも鳴るようにしてあります。

## できること

- 提出物の登録（名前、Classroom か紙か、期限、かかる時間、先生の名前）
- 開始時刻の通知。ロック画面に全画面で出ます
- 締切3日前からのリマインダー
- 残り時間のカウントダウン
- 完了したものの記録

余裕時間は全部の課題で共通の設定です。初期値は30分です。

## 権限

通知、正確なアラーム、おやすみモードあたりの権限を使います。足りていないと鳴らないので、アプリの設定画面で今の状態を確認できるようにしてあります。テスト通知も本番と同じ経路で鳴ります。

## つくり

Kotlin + Jetpack Compose、Room、DataStore。通信は一切しないので、データは端末の中だけにあります。

## 環境

- compileSdk 37 / targetSdk 36 / minSdk 24
- JDK 17 以上
- 署名の設定は `keystore.properties.example` を参照
